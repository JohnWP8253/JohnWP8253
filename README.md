## Featured Work

My company code is proprietary, so these are case studies and not repositories.

### [MOB/GLOB RAG Pipeline](https://gist.github.com/JohnWP8253/c2f1c273fabe4eb63500679eff098825)

A RAG pipeline on AWS Bedrock (Knowledge Base, Converse, and Guardrails) with Lambda, S3, and CloudWatch. It turns 36 lesson plans per grade into 12 module overviews and a grade level overview.

- Six grade levels run in 8 minutes.
- Turnaround dropped from weeks or months to days.
- Production costs fell by over $100K.
- An agent handles only the generative step. Everything else is deterministic.
- Human-in-the-loop review gates and CI/CD are built in.

### [WCAG 2.2 Accessibility GPT](https://gist.github.com/JohnWP8253/fd35bbc6081b8644bb155991009d0d14)
